# Organizations API

Небольшое API-приложение для работы с организациями, зданиями и видами деятельности. Асинхронный вариант.

------------------------------------

## Стек
- Python 3.11
- FastAPI
- SQLAlchemy
- Pydantic
- MySQL 8
- Docker / Docker Compose

------------------------------------

## Функциональность
- Слоистая архитектура:
  - `core` — конфигурация приложения
  - `db` — подключение к базе и сессии
  - `repositories` — доступ к данным (Repository pattern)
  - `services` — бизнес-логика (Service layer)
  - `api` — зависимости и маршруты FastAPI
- Получение организаций:
  - по адресу здания
  - по ID организации
  - по имени
  - по радиусу относительно точки
  - по виду деятельности (с учётом дерева)
- Иерархическая модель деятельностей (до 3 уровней вложенности)
- Доступ к API по статическому API-ключу
- Все ответы в формате JSON
 - Эндпоинт `/health` для проверки работоспособности сервиса и БД

------------------------------------

## Требования
- Docker
- Docker Compose

## Тестирование

Локальный запуск тестов (используется in-memory SQLite, Docker не нужен):

```bash
pip install -r requirements.txt
pytest -q
```

------------------------------------

### Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <repo_url> # дописать
cd organizations-api
```

### 2. Собрать и запустить контейнеры

```bash
docker-compose up --build
```

### 2. Документация API (Swagger UI)

http://localhost:8000/docs

### 3. Все запросы требуют API-ключа в заголовке

По умолчанию приложение ожидает ключ `API_SECRET_KEY`, но в production
рекомендуется переопределять его через переменную окружения `API_KEY`.

Пример заголовка:

X-API-Key: SUPER_SECRET_KEY

### 4. Остановка контейнеров

```bash
docker-compose down -v
docker-compose up --build
```

#### Дополнительная информация

В проекте используются seeds - тестовые данные загрузятся автоматически при сборке контейнера

- 4 здания
- 10 видов деятельности организаций (3 уровня вложения, например: Автомобили -> легковые -> запчасти)
- 4 организации
- 6 номеров телефонов (у некоторых организаций несколько номеров)
